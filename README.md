# maidenpeter.github.io

Front page for my Kenya insurance work: https://maidenpeter.github.io

Every general insurer and reinsurer in Kenya, every quarter from Q4 2016 to Q1 2026, rebuilt from the Insurance Regulatory Authority's returns and turned into analysis:

- [Kenya Insurance Loss Map](https://maidenpeter.github.io/ira-kenya-insurance/page/kenya-insurance-loss-map.html): where the money is lost, class by class
- [Kenya Insurance Market Structure](https://maidenpeter.github.io/ira-kenya-insurance/page/kenya-insurance-market-structure.html): concentration, share shifts and the cost of fragmentation
- [Kenya Cedant Scorecard](https://maidenpeter.github.io/ira-kenya-reinsurance/page/kenya-cedant-scorecard.html): every insurer graded the way a reinsurer screens a cedant
- [Kenya Insurer Explorer](https://maidenpeter.github.io/ira-kenya-data/explorer/kenya-insurer-explorer.html): any insurer, any year

Code: [ira-kenya-data](https://github.com/maidenpeter/ira-kenya-data), [ira-kenya-insurance](https://github.com/maidenpeter/ira-kenya-insurance), [ira-kenya-reinsurance](https://github.com/maidenpeter/ira-kenya-reinsurance).

`build_site.py` writes this page and the index page of each project repo, so the site stays in one style. Run `python build_site.py <output folder>`.
